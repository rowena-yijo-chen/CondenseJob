# CondenseJob

## The Transparency Layer for Remote Hiring

Save Your Energy from Job Hunting Burnout.

CondenseJob is an AI-powered browser extension and companion platform that helps users evaluate remote jobs before applying.

The platform visualizes trust signals directly on job listings and helps users identify:
- scam risks
- low transparency hiring
- misleading job postings
- poor job matches
- overwhelming application processes

## Features

- Real-time AI trust analysis
- Scam risk detection
- Visual trust color system
- Personalized match scoring
- Community & employee insights
- Saved jobs & comparison
- AI hiring transparency signals
